## WordPress 기준 기능과 데이터

| 원본 영역 | 원본 구조와 동작 | 이전 대상 |
|---|---|---|
| 테마 헤더·홈·뷰 | 사이트 설정, 검색, 탭, 모바일 메뉴, 홈 슬라이드, 갤러리, 푸터 | 공통 레이아웃, 서비스 페이지, 홈 배너 |
| 상품·메뉴·색상 | 상품 CPT 및 분류, 제조사, 용량별 출고가, 색상별 사진 | 제조사, 상품, 분류, 용량, 색상, 상품 조건 |
| 요금제·가격 | 통신사 요금제, 가입 유형, 용량 매칭, 공통지원금과 추가지원금, 선택약정, 할부 | 서버 견적 및 공유 계산 함수 |
| 고객 폼·상담 | 조건 미정/견적 상담, 이름·생년월일·전화, 잔여 금액, 동의 및 신청번호, 조회 | 상담 저장 및 번호·전화 확인 조회 |
| 상담 운영 | 상태 변경, 보관 기간, 상담 텍스트, 신규·지연 현황 | 관리자 상담 목록, 상태, 조회, 보관 정책 |
| 고객 게시판 | 공지, 후기, 질문답변, FAQ, 공개 상태 | 콘텐츠 조회, 등록 및 관리자 게시 |
| 이미지·사이트 설정 | 대표/색상 사진, PC/모바일 배너, 크기 맞춤, 영상, 순서, 자동 넘김, 문의 정보 | 배너·콘텐츠·사이트 설정 및 파일 저장 |
| 일괄 작업 | 상품/요금제/지원금 엑셀, 변경 확인, 수동 금액과 만료 | XLSX 검증·가져오기·내보내기 |
| 지원금 연동 | SKT 및 SmartChoice, 외부 JSON, 매핑, 실패/예약 기록 | 지원금 동기화와 출처·실행 상태 |
| 워드프레스 관리자 | 상품/게시판/미디어/계정, 플러그인·테마 등 플랫폼 관리 | 앱 계정과 업무 기능. WordPress 플랫폼 메뉴는 독립 앱 구조로 대체 |
| 보험 | 상담 채팅/분기, 보험 관리 | 보험 소개 및 상품 상세 UI로 변경 |

관계형 데이터는 제조사 → 상품 → 용량/색상과 통신사 → 요금제로 나눈다. 조건은 상품·용량·요금제·가입 유형을 조합한다. 상담은 상품 수정 이후에도 당시 계산 결과와 동의 내용이 유지되도록 스냅샷을 저장한다. 세션에는 원본 토큰 대신 해시를 저장한다. 배너, 콘텐츠와 설정은 공개 가능한 항목만 고객용 API에 노출한다.
