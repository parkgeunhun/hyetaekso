# WordPress 데이터 이전

운영과 분리된 DB에서 검토합니다. 원본 WordPress와 작업 전 DB의 백업을 보존하세요. 고객 정보가 들어간 파일은 Git에 올리지 않습니다.

1. 기존 WordPress에서 휴대폰 엑셀과 요금제 목록을 내보냅니다. 새 관리자에서 통신사와 요금제를 먼저 등록합니다. 조건 시트의 통신사, 요금제 이름, 월정액이 정확히 일치해야 합니다.
2. 아래 검토 명령은 상품·용량별 출고가·조건·색상을 데이터베이스에서 검증하고 변경을 되돌립니다. 행 수와 가격을 대조한 뒤 스테이징에서만 적용합니다.
3. 이 스크립트는 XLSX의 관리코드로 일관된 ID를 계산합니다. 기존 DB에서 행을 삭제하지 않습니다. 조건과 색상을 빼고 다시 올려도 남아 있으므로 삭제는 관리자에서 확인 후 수행합니다. 원본 공통지원금과 조회 코드는 휴대폰 XLSX 계약에 없으므로 별도 이전해야 합니다. 상품 상세 HTML은 안전한 일반 텍스트로 변환하며 HTML 스타일·배지는 자동으로 이관하지 않습니다.
4. 기존 이미지 링크는 새 도메인에서 접근 가능한 HTTPS 링크인지 확인하세요. WordPress의 임시 Playground URL이면 원본 이미지를 내려받아 새 관리자에서 파일로 다시 올립니다.

```sh
node --env-file-if-exists=.env scripts/import-wordpress-phones.mjs "<기존 휴대폰 XLSX>"
node --env-file-if-exists=.env scripts/import-wordpress-phones.mjs "<기존 휴대폰 XLSX>" --apply
```

회사 정보, 배너, 공지, FAQ, 후기, 질문답변은 관리자 화면이나 새 XLSX 양식으로 옮길 수 있습니다. WordPress 상담 데이터, 과거 신청번호, 동의 버전, 개인정보 보관 이력의 자동 변환은 제공하지 않습니다. 실제 DB 덤프가 준비되면 이력을 보존하는 변환과 대조를 별도로 수행해야 합니다.
