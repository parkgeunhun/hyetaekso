# 구현 및 검증 상태

| 영역 | 전환 상태 |
|---|---|
| 공개 화면 | 홈, 소개, 통신, 렌탈, 이사·홈, 공간, 모빌리티, 사업자 서비스, 가맹안내, 고객센터, 보험의 React 화면을 구성했습니다. 기존 휴대폰, 신청, 조회, 공지, FAQ, 후기, 질문답변을 별도 경로에서 사용할 수 있습니다. |
| 보험 | 소개, 상품 카드, 상세, 절차 안내만 있습니다. 보험 채팅, 보험 데이터 수집, 보험 관리자 기능을 포함하지 않습니다. |
| 휴대폰 | 용량별 출고가, 다중 카테고리, 색상별 이미지, 통신사별 요금제, 가입 유형별 추가지원금, 할인과 할부를 계산합니다. API가 신청 시 가격을 다시 검증합니다. |
| 지원금 | 수동 및 XLSX, SKT 공개 조회, 스마트초이스, 지정 JSON 피드, 만료·불일치 처리, Worker의 오전 9시 KST 예약 설정이 있습니다. 운영 단말·요금제 코드를 매핑해야 하며 현재 등록 기기의 실제 지원금과 실시간 갱신 결과는 미검증입니다. 원본 카탈로그 자동 추천 UI는 이전하지 않았습니다. |
| 상담 | 필수 입력·동의, 견적 스냅샷과 텍스트 요약, 신청번호 조회, 관리자 검색·상태·메모를 구현했습니다. 기존 신청 이력·신청번호의 자동 이전과 외부 SMS·카카오 전송은 포함하지 않습니다. |
| 관리자 | 세션 기반 로그인, 대시보드, 카탈로그 관리, 지원금, 상담, 배너, 게시물, 회사 및 상담 설정, 미디어 업로드, XLSX 검토·반영을 구현했습니다. WordPress 플러그인 설치, 테마, 역할 관리 등 범용 CMS 기능은 포함하지 않습니다. |
| 엑셀·이전 | 새 XLSX 양식의 검토/적용과 기존 휴대폰 엑셀의 CLI 검토/적용을 제공합니다. 실제 운영 DB나 첨부 파일을 변경하지 않았습니다. 기존 지원금 매핑·상담·배너·설정의 전체 자동 변환은 남았습니다. |
| 배포 | Workers 번들 및 Pages용 빌드 구성이 있습니다. 실제 Cloudflare 계정의 보호된 미리보기와 iPad Safari 기기 검증은 별도로 필요합니다. |

별도 bareun-ieum-main.zip 파일을 찾을 수 없어 작업공간의 기존 WordPress 저장소와 배포 패키지를 기준으로 기능을 분석했습니다. 실제 WordPress 운영 데이터나 기존 사이트는 변경하지 않았습니다.

## 검증 명령

- npm test: 격리된 DB의 API, 가격, 입력 검증, 로그인 및 권한, 상담·엑셀 흐름과 지원금/동영상 응답을 검사합니다.
- LEGACY_PHP: 지정된 PHP에서 원래 PHP 견적 공식의 결과를 비교합니다.
- MYSQL_TEST_URL: 별도로 만든 MySQL 테스트 DB를 지정하면 SQLite와 같은 API 흐름을 반복합니다.
- npm run build: Vite 프로덕션 빌드 및 공개 경로 사전 렌더링.
- npm run test:browser: 빌드된 파일을 별도 SQLite 인메모리 서버로 열고 데스크톱·태블릿·모바일과 관리자·상담 동작을 확인합니다. iPad 실제 기기 검증과 별개입니다.
- npm run worker:check: Worker 배포 없이 번들 검증.
